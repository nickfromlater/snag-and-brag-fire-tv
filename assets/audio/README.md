# Snag & Brag audio files

Generated by [tools/render-audio](../../tools/render-audio/README.md) from the unchanged mockup audio block. 112 SFX + 6 four-bar music loops.

Run `pnpm --filter render-audio build` from the repo root. `pnpm --filter render-audio verify` regenerates into a temporary directory and compares every audio, manifest, README and QA byte.

The WAVs are 48 kHz stereo PCM16. Ogg copies use Vorbis q5. Audio payload totals: **17134292 WAV bytes + 1562115 Ogg bytes = 18696407 bytes (17.83 MiB)**.

## Uniform export gain and TV mix

Per the lead's 2026-10-12 review, every effect and music file receives the same **+10.93534137 dB** gain (3.521819293883×) after the original render/trim/cut and before PCM16 quantization. Loudest source: sfx-snagged, -13.93534137 dBFS; boosted bank peak: **-2.99998782 dBFS**, targeting -3.0 dBFS. There is no per-file normalization, added compression or limiting. The gain is already baked into WAVs and their Ogg copies.

The unchanged source render uses SFX .8, music .22, master .9, reverb .18 wet, with the original -12 dB / 4:1 compressor; those source gains/compression remain baked in. Every boosted file plays at **unity gain (1.0)**, summed at unity then passed through the TV soft limiter. Original SFX/music/master levels, compressor and makeup are baked in and must not be applied again. The only runtime gain changes are Sound/Music on-off toggles (1.0/0.0) and optional user volume if added. `mix.makeupGainDb`, `runtimeBusLevels` and `filePlaybackLevels` specify that contract. Single-file compression cannot reconstruct the original compressor acting on overlapping synth voices.

Requested overlap, all starting at sample 0: music-win, sfx-fanfare, sfx-ko and sfx-crowd-2-18, every file at unity (1.0). The signed PCM16 samples are summed in float64, with silence after each file ends, before the TV soft limiter. Peak is **-1.28862966 dBFS at unity before the soft limiter**, with 0 channel samples / 0 stereo frames above 0 dBFS. Minimum attenuation to stay below full scale is 0.00000000 dB; the TV limiter's knee/threshold determine its actual reduction. [Overlap details](../../docs/review/audio/runtime-overlap.json) are also in `mix.runtimeOverlap`. The standalone crowd is intentionally included for this stress case although fanfare already embeds its own crowd.

Every file has parameters, seed, hashes (including its unboosted PCM16 source hash), source/exported peak, RMS, duration, ffmpeg ebur128 integrated loudness and call sites in [manifest.json](manifest.json). Loudness -70 LUFS on short effects is the meter's empty-gate floor. Four-bar sample boundaries and numeric seam evidence are under each music file's `loop`. Spectrograms and the waveform grid are in [docs/review/audio](../../docs/review/audio/README.md).
